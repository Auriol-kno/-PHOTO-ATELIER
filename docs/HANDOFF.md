# PHOTO ATELIER — development handoff

Repository: `Auriol-kno/-PHOTO-ATELIER`
Working branch: `feature/mobile-foundation-v0.1`

## Project direction

Mobile-first photography learning and color-style comparison app focused on Nikon Zf and workflows for Lightroom Classic.

## Planned modules

- Dashboard
- Style Library (Hasselblad, Leica, Kodak, Fujifilm)
- Compare Lab
- Lightroom Studio
- Nikon Studio
- Color Science
- Academy
- Photo Missions
- AI Photo Mentor
- Portfolio
- Reference Library
- Settings

## Collaboration rules

- Develop on feature branches; do not merge to `main` without user approval.
- Clearly distinguish visual mockups, functional prototypes and verified color emulations.
- Keep changes documented and test functionality before pull requests.
- Avoid committing user photos or unlicensed third-party image assets.

## First implementation milestone

Transfer the approved mobile prototype into a maintainable web app, then validate navigation and responsive layouts before color processing work.
