# ROADMAP

- **v0.2 — obecna gałąź:** mobilna PWA, nawigacja pełnego zestawu modułów, import z systemowego picker'a, IndexedDB miniatur i indeksu, backup JSON, Compare Lab demo, dokumentacja cloud.
- **v0.3:** rozdzielenie ekranów na komponenty TypeScript + React, testy E2E, własne/zweryfikowane zdjęcia demo, wykrywanie metadanych EXIF, tagi i albumy.
- **v0.4:** konta opcjonalne i chmurowe synchronizowanie samego katalogu oraz miniaturek (Supabase + RLS).
- **v0.5:** wrapper iOS (Capacitor lub Expo po porównaniu), natywny document picker/iCloud, trwałe referencje do plików po zgodzie.
- **v0.6:** sprawdzony eksport Lightroom XMP i zarządzanie wersjami, integracja z desktopowym Lightroom Classic.
- **v0.7:** Windows companion do folderów NEF/NAS, wsadowy podgląd RAW i background re-index.
- **v1.0:** skalibrowane laboratorium koloru (ICC/DNG), oryginalne zestawy referencyjne, walidacja Nikon NP3 w NX Studio/Zf, Photo Mentor z kontrolą prywatności.
